# Better Quiz Box

交互式多项选择题块插件。在 Obsidian 笔记里用 ` ```quiz ` 代码块渲染可交互的测验：**纯瞬态作答**（点击只在内存/DOM 生效，绝不写回笔记文件），题干、选项、解析全部支持 **Markdown / LaTeX**，内置三种作答模式，并与间隔重复（Spaced Repetition）复习流程友好配合——翻面重渲染会保留你的顺序和作答。

本地配置示例：

````markdown
```quiz
<!-- mode: non-immediate -->
均值检验的原假设通常是什么？

[ ] $\mu = \mu_0$
[c] $H_0: \mu = \mu_0$
[c] $H_0: \mu \le \mu_0$
[h] 双边检验 $H_0: \mu=\mu_0$；单边检验取 $\le$ 或 $\ge$。
```
````

---

## 特性

- **纯瞬态作答**：怎么点都只影响当前渲染，笔记源文件一个字不改。
- **三种模式**：`static`（静态答案展示）、`immediate`（点选即判对错）、`non-immediate`（点选不判，多选用）。
- **Markdown / LaTeX**：题干、选项、解析都走 Obsidian 渲染器，数学公式原生支持。
- **选项多行**：选项之间可按回车续行，无需缩进。
- **自动打乱**：动态块缺省随机打乱选项；每次"新开"（新容器 / 换卡 / 重开文件）重新随机。
- **顺序绑定**：`bind` 可让静态块跟随某个动态块的打乱顺序，正反面永不打架。
- **SR 友好**：同卡翻面重渲染时保持已作答状态与选项顺序。
- **自动去重**：完全相同的选项文本会被去重。
- **选项编号**：可选用 `abc` 或 `1 2 3` 标签显示，纯显示层、不写入内容。

## 语法

代码块语言标记固定为 `quiz`。正文结构：

```
题干(支持多行 / Markdown / LaTeX)
[ ] 选项A(未选)
[c] 选项B(正确项)
...  其他选项
[ h ] 解析 / 说明(可选;放在末选项之后)
```

- `[ ]` —— 普通选项。
- `[c]` —— 正确选项。遗留写法 `[w]` / `[r]` 一律按未选处理。
- `[h]` —— 解析说明标记。位于末选项之后；其后的文本（含同行余文、后续行）作为解析。**无 `[h]` 时，末选项之后的文本按旧规则整段视为解析。** 要让末选项多行续行，需以 `[h]` 收尾。

### 块属性（可选）

用一整行 HTML 注释书写，放在块内任意位置、每个属性一行、**首个生效**：

| 属性 | 取值 | 缺省 | 说明 |
|------|------|------|------|
| `mode` | `static` / `immediate` / `non-immediate` | `immediate` | 作答模式 |
| `shuffle` | `on` / `off` | `on`（仅动态块） | 是否打乱选项 |
| `number` | `abc` / `123` / `none` | `none` | 选项编号样式 |
| `id` | 任意名字 | 自动 | 动态块标识 |
| `bind` | 任意名字 | 自动 | 静态块绑定某动态块的顺序 |

同一行可写多条，用逗号 / 分号分隔，如 `<!-- mode: static, number: abc -->`。

### 三种模式速查

| 模式 | 行为 | 用途 |
|------|------|------|
| `static` | 直接高亮正确答案，整块不可点 | 讲义 / 答案页 |
| `immediate` | 点选即判：对绿 ✓、错红 ✗，答错揭示正确项 | 快速自测 |
| `non-immediate` | 点选只高亮，不判对错；≥2 个正确项自动转多选 | 先自主作答再对答案 |

## 安装

### 手动（尚未上架市场时）

1. 下载最新 [Release](../../releases) 里的 `main.js`、`manifest.json`、`styles.css`。
2. 放入 vault 的 `.obsidian/plugins/better-quizbox/` 目录。
3. 设置 → 第三方插件 → 启用 **Better Quiz Box**。

### BRAT(可选)

安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，添加 `Junzi-ana/better-quizbox` 即可跟随 GitHub Release 更新。

## 开发者

源码与构建在 `src/` 下，模块划分清晰（解析 / 状态 / 渲染 / 入口）。改完源码后：

```bash
npm install
npm run build   # esbuild 打包 main.js + 同步样式/manifest
```
